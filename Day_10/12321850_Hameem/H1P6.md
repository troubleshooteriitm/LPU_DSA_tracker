# **Word Pattern**
# https://leetcode.com/problems/word-pattern/submissions/2054331369/
```python
class Solution:
    def wordPattern(self, pattern, s):
        arr = s.split()
        if len(arr) != len(pattern):
            return False
        for i in range(len(arr)):
            if pattern.find(pattern[i]) != arr.index(arr[i]):
                return False
        return True
```
