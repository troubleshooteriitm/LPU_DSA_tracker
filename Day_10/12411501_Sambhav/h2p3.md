#h2p3Linked List Cycle

link - https://leetcode.com/problems/linked-list-cycle/description/

```python

class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        seen =set()
        cur=head
        while cur:
            if cur in seen:
                return True
            seen.add(cur)
            cur= cur.next
        return False

```
