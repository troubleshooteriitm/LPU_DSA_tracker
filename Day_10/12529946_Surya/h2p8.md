# 287. Find the Duplicate Number : https://leetcode.com/problems/find-the-duplicate-number/description/
## Solution1 : Binary Search
``` Python
class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        l =1
        r = len(nums)-1
        while(l<r):
            mid = (l+r)//2
            count = 0
            for n in nums:
                if n<=mid:
                    count = count + 1
            if count>mid:
                r = mid
            else:
                l = mid + 1
        return l

```
## Solution2 : Floyd Hare and Tortoise(Linked List)

```Python
class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        slow = nums[0]
        fast = nums[0]
        while True:
            slow = nums[slow]
            fast =nums[nums[fast]]
            if slow==fast:
                break
        slow = nums[0]
        while slow!=fast:
            slow = nums[slow]
            fast = nums[fast]
        return slow
```
