# **Remove Element**
# https://leetcode.com/problems/remove-element/submissions/2051039417/?envType=problem-list-v2&envId=array
```python
class Solution:
    def removeElement(self, nums: List[int], val: int) -> int:
        k = 0

        for i in range(len(nums)):
            if nums[i] != val:
                nums[k] = nums[i]
                k += 1

        return k
    ```
