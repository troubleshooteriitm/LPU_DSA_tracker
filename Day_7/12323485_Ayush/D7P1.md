# Valid Parentheses

## Problem Link
https://leetcode.com/problems/valid-parentheses/

## Solution

```python
class Solution:
    def isValid(self, s: str) -> bool:
        st=[];m={')':'(',']':'[','}':'{'}
        for c in s:
            if c in m:
                if not st or st.pop()!=m[c]: return False
            else: st.append(c)
        return not st
```
