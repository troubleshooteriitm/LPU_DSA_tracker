# Min Stack

## Problem Link
https://leetcode.com/problems/min-stack/

## Solution

```python
class MinStack:

    def __init__(self):
        self.s=[];self.m=[]

    def push(self, val: int) -> None:
        self.s.append(val)
        if not self.m or val<=self.m[-1]: self.m.append(val)

    def pop(self) -> None:
        if self.s[-1]==self.m[-1]: self.m.pop()
        self.s.pop()

    def top(self) -> int:
        return self.s[-1]

    def getMin(self) -> int:
        return self.m[-1]
```
