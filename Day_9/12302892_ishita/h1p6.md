## Solution 2 (optimized with Binary search)
- when n=1024 binary search takes 8 iterations  , but while loop takes 32 iterations

```python

class Solution(object):
    def mySqrt(self, x):
        left, right = 0, x

        while left <= right:
            mid = (left + right) // 2

            if mid * mid <= x:
                left = mid + 1
            else:
                right = mid - 1

        return right

```
